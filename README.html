Start in three steps

  1. Extract the whole ZIP into a folder. Do not open only index.html from inside the ZIP.
  2. Double-click index.html. Use a modern browser with JavaScript enabled. Keep the other files and folders beside it.
  3. Begin with Module 00. Read, predict the example, try the visual, answer the check and write an explanation in your own words.

No sign-in, installation or internet connection is needed for lessons, labs, quizzes, notes or bundled PYQ papers. External verification links require internet. Browser PDF support varies; open the linked paper directly if its inline viewer is unavailable.

Notes and progress

  • Download notes from any module, or use all revision notes already included in the ZIP. Print that page and choose “Save as PDF” if you prefer a PDF.
  • Use Save lesson, personal notes, recall cards and the mistake notebook from the guide.
  • Progress lives in this browser at this file location. Moving folders, using another browser or clearing storage can make it unavailable. Use Export progress to save a JSON backup, then Import progress to restore it.
  • Activity completion and quiz accuracy are different measures. Revealing a solution does not count as a correct answer or a completed attempt.

How the PYQ practice works

Each card identifies the year, session, official question number and PDF page. Read the original question and option order in its bundled paper, then enter the answer in the guide. Read the guide’s own solution explanation after attempting; the official answer key is linked when available. Independently checked answers are clearly labeled and include a secondary online cross-check; their explanations are included offline. Some old papers number the subject section separately from General Aptitude, so follow the card’s paper and session carefully.

Scope and C conventions

Checked against GATE CS 2027 Section 4. Complexity, searching and traversals are supporting bridges to Algorithms; this guide does not cover the whole GATE CSE syllabus. C17 rules are used unless an exam question states a different model.

The interactive labs are guided simulations, not a general C compiler. Complete C examples are distinguished from fragments and pseudocode. Module 01 explains compiling a file if you install GCC or Clang separately. No compiler is included.

Project structure

  • index.html — app shell and learning engine
  • modules/ — foundation plus new lesson and question content
  • labs.js — interactive models
  • study.js — search, recall, notes and progress tools
  • pyqs.js and source-catalog.json — source-linked question metadata
  • papers/ — original question papers and available official answer keys, retained with their attribution
  • revision-notes/ — ready-to-use Markdown and printable HTML notes

The supplied original ZIP was left unchanged. Its existing foundation was revised only in this new copy. All other modules were completed in this separate edition.

Validation

All module registrations and question schemas checked; arithmetic, binary search, postfix evaluation, heap operations, graph traversals and tree traversal models tested. Every lesson was opened in the browser, including narrow-screen layout checks. C snippets were checked for display-escaping errors; a native C compiler was not run. Browser checks used a local HTTP preview; direct file launch was not automated because the preview browser blocks file URLs. The app uses classic local scripts and has no network runtime dependencies.
